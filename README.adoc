= Serve LLMs on Intel Xeon CPUs -- Lab

This repository contains a guided, hands-on lab for the https://github.com/rh-ai-quickstart/llm-cpu-serving[llm-cpu-serving] quickstart.

== Running locally

[source,bash]
----
npx antora default-site.yml
open www/index.html
----

== Structure

* `content/` -- Antora lab content (AsciiDoc pages, images)
* `content/supplemental-ui/` -- Showroom UI extensions (send-to-terminal, branding)
