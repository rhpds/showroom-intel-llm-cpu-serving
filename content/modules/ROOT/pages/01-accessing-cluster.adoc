= Accessing the Cluster

In this module you will log into the OpenShift cluster and verify the lab environment.

== Log into OpenShift

Open the OpenShift Console using the link in the right panel, or navigate to:

{openshift_console_url}

Log in with:

* **Username:** `{user}`
* **Password:** `{password}`

== Verify from the terminal

In the terminal panel on the right, log in via the CLI:

[source,bash,role="execute",subs="attributes+"]
----
oc login -u {user} -p {password} {openshift_api_url}
----

Verify your project exists:

[source,bash,role="execute",subs="attributes+"]
----
oc project {project_name}
----

Check that pods are running:

[source,bash,role="execute",subs="attributes+"]
----
oc get pods
----

You should see the quickstart pods in a `Running` state.

== Verify the application

Check that the application route is accessible:

[source,bash,role="execute",subs="attributes+"]
----
oc get routes
----

You are now ready to explore the application.
